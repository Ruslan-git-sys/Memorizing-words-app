# Memorizing_words_app - Приложение для заучивания слов
Приложение для эффективного запоминания слов с помощью карточек и интервальных повторений. Подходит для изучения иностранных языков, терминов, списков и т. п.

## Особенности

- Карточки: слово ↔ перевод, можно добавлять примеры фраз.
- Режим заучивания: показ слова → ввод перевода → проверка.
- Режим повторения: карточки по алгоритму интервальных повторений (SRS).
- Статистика: прогресс, количество выученных слов, текущая сессия.
- Локальное хранение данных в браузере (localStorage).
- Адаптивный интерфейс (mobile‑first).

## Установка и запуск

### Требования

- Современный браузер (Chrome, Firefox, Edge).
